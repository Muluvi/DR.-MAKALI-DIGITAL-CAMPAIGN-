# Team quick guide

For Dr. Mulu's team. Five minutes to read. You never need GitHub, a terminal or code.

## Viewing

Anyone with the link can see everything, without an account:

- **Explore data** (`/explore`): every dataset. Search, filter, sort. **Link** copies the exact view; **CSV** downloads it; **PDF** prints it.
- **Dashboards** (`/dashboards`): the team's numbers and the data pack, as charts.
- **Strategies** (`/strategies`): every objective, strategy, workstream and response, with the figures behind each.
- **Implementation** (`/progress`): who is doing what, on which channel, and where it stands.
- **Workspace** (`/workspace`): the team's working records.
- **Changes** (`/history`): every change and when it was made.
- **Models** (`/models`): set the options, or type an instruction such as "turnout 70% in Mwingi North", and see the outcome explained. **Save this scenario** keeps it in the workspace for a brief.

## No sign-in

There are no accounts. Anyone with the link can add and change records, so:

- never type a name, phone number, ID number or email address: the forms refuse them;
- if you see a change that should not be there, tell Firefly, or put it back yourself from **Changes**.

## Your day-to-day work (the workspace)

Open **Workspace**, pick a page, tap **Add**, fill the form and tap **Save**. It is on the site at once.

| To do this | Use |
|---|---|
| Issue the weekly brief (Thursday) | **Weekly brief**: pillar weights must add up to 100 |
| Plan, assign, approve and mark posts published | **Content calendar**: Kikamba is approved only after the native-speaker review box is ticked |
| Plan and log SMS, USSD and WhatsApp sends | **Dispatch**: bulk SMS in Kikamba is refused; SMS must be lodged with the operator 48 hours ahead |
| Record each indicator's measured value | **KPI tracker** |
| Record reach from the platform exports | **Channel audit** |
| Design, run and read creative tests | **Creative tests** |
| Log what the wards are saying | **Field and sentiment** (never record who said it) |
| Log rival activity from public sources | **Competitor watch** |
| Handle an attack, or log a red-team drill | **Rapid response** |
| Track who is doing what for each strategy | **Implementation** |
| Record project verification visits | **Service-delivery tracker** |
| Record meeting decisions | **Meetings and decisions** |

To change a record, tap **Edit** on it.

**Never enter a supporter's name, phone number or ID.** The site is open to anyone with the link. Supporter records stay in the campaign's own systems; the platform holds counts.

## Updating the data (figures, register, lists)

Open **Edit data** (`/edit-data`).

- **Figures**: search for the figure, change the value, source or date, then tap **Submit edit**. If something is wrong, for example a sourced figure with no source, the form tells you what to fix before anything is sent.
- **Register**: pick the ward and enter the number. Leave "update the totals" ticked.
- **Strategy lists**: indicators, risks, segments, escalation tiers, contenders, radio stations, pillars, content types and benchmarks.
- **Analysis**: the analysis model's published values. Tell Firefly when you change one.

After you submit, the site runs its full data checks. If they pass, the change is live in a few minutes. If they fail, nothing on the site changes, and **Changes** shows the edit as refused.

## Putting a mistake right

1. Open **Changes**.
2. Find the change. It shows what it was before and after.
3. Tap **Revert** and confirm.

The previous version comes back exactly. A revert is itself logged, so it can be reverted too.

## Who to ask

Firefly runs the platform: hosting, accounts, fixes and new features. Ask Firefly if the site misbehaves, if you need an account added or removed, or if you need a function the platform does not have yet.
